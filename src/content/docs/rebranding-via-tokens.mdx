Cosmo uses Tailwind CSS v4, where every variable declared under `@theme` in [src/styles/global.css](src/styles/global.css) becomes a Tailwind utility automatically.

## How it works

Add or change a token under `@theme`:

```css
@theme {
  --color-brand-primary: oklch(0.62 0.19 250);
  --font-display: "Inter", sans-serif;
}
```

Then use it as a utility anywhere:

```astro
<h1 class="bg-brand-primary font-display">Hello</h1>
```

<Callout type="tip">
  Token names map directly to utility names. `--color-brand-primary` becomes `bg-brand-primary`, `text-brand-primary`, `border-brand-primary`, and so on.
</Callout>

## Where to start

1. Open [src/styles/global.css](src/styles/global.css)
2. Replace the placeholder color tokens with your brand palette
3. Update the font tokens and the matching `<link rel="preload">` tags in `src/layouts/BaseLayout.astro`
4. Swap the hardcoded `bg-white text-neutral-900` body classes in `BaseLayout.astro` for your brand tokens

<Callout type="warning" title="Don't preload too many fonts">
  `BaseLayout.astro` preloads two fonts by default. If a single font covers above-the-fold content, drop one preload — extra preloads block render.
</Callout>
